# cmd/server

В данной директории содержится код Сервера метрик, который компилируется в бинарное приложение.

## Конфигурация

Сервер поддерживает следующие параметры конфигурации:

### Флаги командной строки:
- `-a` — адрес и порт для запуска сервера (по умолчанию: `:8080`)
- `-i` — интервал сохранения метрик в файл в секундах (по умолчанию: `300`)
- `-f` — путь к файлу для сохранения метрик (по умолчанию: `./metrics.json`)
- `-r` — загрузить сохраненные метрики при старте сервера (по умолчанию: `false`)
- `-l` — уровень логирования (по умолчанию: `info`)
- `-e` — окружение: `prod`, `local` (по умолчанию: `local`)
- `-d` — строка подключения к PostgreSQL (по умолчанию: пусто)
- `-k` — ключ для хеширования (по умолчанию: пусто)
- `-crypto-key` — путь к приватному ключу RSA (по умолчанию: `./private.pem`)
- `-t` — доверенная подсеть в нотации CIDR (по умолчанию: пусто)

### Переменные окружения:
- `ADDRESS` — адрес и порт сервера
- `STORE_INTERVAL` — интервал сохранения метрик
- `FILE_STORAGE_PATH` — путь к файлу хранения
- `RESTORE` — загрузить метрики при старте
- `LOG_LEVEL` — уровень логирования
- `ENVIRONMENT` — окружение
- `DATABASE_DSN` — строка подключения к БД
- `KEY` — ключ для хеширования
- `CRYPTO_KEY` — путь к ключу RSA
- `TRUSTED_SUBNET` — доверенная подсеть в нотации CIDR

### JSON конфигурация:
Можно использовать JSON-файл конфигурации. Пример см. в `configs/server.json`.

## Функция доверенной подсети

Сервер поддерживает ограничение доступа к эндпоинтам обновления метрик на основе IP-адреса клиента.

### Как это работает:

1. Установите переменную окружения `TRUSTED_SUBNET` или флаг `-t` со значением в формате CIDR (например, `192.168.1.0/24`)
2. Агент должен отправлять заголовок `X-Real-IP` со своим IP-адресом
3. Сервер проверяет, что IP входит в указанную подсеть
4. Если IP не входит в доверенную подсеть, сервер возвращает статус `403 Forbidden`
5. При пустом значении `TRUSTED_SUBNET` все запросы обрабатываются без ограничений

### Примеры:

```bash
# Разрешить доступ только из локальной сети
./server -t 192.168.1.0/24

# Или через переменную окружения
export TRUSTED_SUBNET="10.0.0.0/8"
./server

# Без ограничений (по умолчанию)
./server
```
