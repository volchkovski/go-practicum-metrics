# cmd/agent

В данной директории содержится код Агента сбора метрик, который компилируется в бинарное приложение.

## Функциональность

Агент собирает метрики из системы (CPU, память и т.д.) и отправляет их на сервер метрик.

### Автоматическая отправка IP-адреса

Агент автоматически определяет локальный IP-адрес хоста и отправляет его в заголовке `X-Real-IP` с каждым запросом к серверу.

Это позволяет серверу:
- Идентифицировать источник метрик
- Применять ограничения доступа на основе доверенных подсетей (CIDR)

Агент выбирает первый не-loopback IPv4 адрес из доступных сетевых интерфейсов.

### Пример работы:

```bash
# Запуск агента
./agent -a localhost:8080

# Агент автоматически:
# 1. Определяет локальный IP (например, 192.168.1.100)
# 2. Собирает метрики
# 3. Отправляет на сервер с заголовком X-Real-IP: 192.168.1.100
# 4. Сервер проверяет IP и обрабатывает запрос
```

## Взаимодействие с сервером

Если на сервере настроена доверенная подсеть (`TRUSTED_SUBNET`), убедитесь, что IP-адрес агента входит в эту подсеть. В противном случае сервер вернет статус `403 Forbidden`.
